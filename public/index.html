Django Learning Projects

Two self-contained Django experiments in one monorepo — run locally with SQLite, not hosted on Vercel.

View on GitHub

django-rest-api

Django REST Framework API for code snippets with Pygments syntax highlighting, owner permissions, and JWT authentication.

  • CRUD at /snippets/
  • JWT at /api/token/
  • Browsable API + HTML feed
Source

django-blog

Authenticated blog with posts, comments, user profiles, and profile search — consolidated from earlier Django 2 experiments.

  • Registration & session login
  • Posts, comments, avatars
  • Profile search by username
Source

Run locally

git clone https://github.com/PiyushMishra318/django-learning-projects.git
cd django-learning-projects/django-rest-api   # or django-blog
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
python manage.py migrate && python manage.py runserver
